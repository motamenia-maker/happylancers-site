# Happy Lancers website

The public website at https://happylancers.app, served by GitHub Pages from this repository.

- `index.html` is the whole site (styles and scripts inline); `assets/logo.png` is the logo.
- Settings at the bottom of `index.html`: `BETA_FORM_URL` (beta sign-up form) and `APP_URL` (the app's public address).
- `build-hosted.js` builds the copy hosted as a claude.ai Artifact.
- `CNAME` points GitHub Pages at the happylancers.app domain.
